# InnoBot Idea Validator

An AI tool to validate business ideas. Input an idea, get SWOT, market score, and recommendations.

## Features
- Input a business idea
- Automatic SWOT analysis
- Market potential score
- Business model recommendations
- Simple roadmap generator

## Tech Stack
Python, Streamlit, OpenAI/Gemini API, Pandas

## Installation
pip install -r requirements.txt
streamlit run app.py
